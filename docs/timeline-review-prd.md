# 时间线复核模式：首期需求

状态：首期（R1–R4）已实现，并在 Canary 通过只读验收（2026-09-29：复核开关、工具条、帖子标签、退出清理正常，复核期间对模型服务的请求数为 0）。整体方向见 `anyfilter-vision.md`，实现方式见 `timeline-review-design.md`。

## 1. 要解决什么问题

现在 AnyFilter 命中规则就直接把帖子折叠掉。想纠错，只能事后翻记录，这时帖子的上下文已经看不到了。

首期做一个**用户主动开启的复核模式**：你正常滚动 X 时间线，每条帖子旁边能看到模型当时怎么判断的，并且当场标注“应隐藏 / 应保留 / 不确定 / 值得看”。标注会连同帖子文本、规则和分数一起存下来，作为以后改规则的参考。

## 2. 已确认的决定

1. **复核时不隐藏**：开启复核模式后，所有已加载的帖子保持可见，只用颜色提示。正常模式照旧隐藏。
2. **绿色是“拟保留”**：适用规则都已判断且没命中。它不代表质量高，也不代表你已认可。你点“值得看”后才变成金色。
3. **标注记两层**：帖子整体结论，加上你实际看过的那几条规则。没看过的规则不会因为你点了“保留”就被记成“没命中”。
4. **分数滑杆只管显示**：它只筛选当前页面上已评分的帖子，不改规则、不改真实阈值、不发新请求。**只保留“命中分不低于 X”这一种滑杆**，不做保留侧的滑杆。
5. **模型辅助推荐金色候选放到以后**（见 `roadmap.md`），首期金色只能手动。

## 3. 用户看到什么

### 3.1 帖子边框

| 状态 | 边框 | 文字 |
| --- | --- | --- |
| 拟隐藏 | 棕红 | 命中规则名和分数，标明“本帖命中”或“线程联动” |
| 拟保留 | 绿色 | “已判断，未命中” |
| 未决 | 琥珀 | 具体原因：请求中 / 请求失败 / 缺上下文 |
| 值得看 | 金色 | “值得看”（你标的） |
| 本地广告规则 | 棕红 | “页面推广标记”，不显示概率 |

颜色之外必须有文字，不能只靠颜色区分。金色和其他状态同时存在时，边框用金色，并保留一个小标签显示模型的原判断。

### 3.2 单帖操作

点击或键盘聚焦帖子上的小标签，在帖子**右侧**浮出一张紧凑的面板（固定在窗口，随帖子滚动，不占用信息流高度；右侧放不下时改放左侧或贴窗口边）：

- 每条规则的分数和阈值。
- 三个按钮：**应隐藏 / 应保留 / 不确定**。选“应隐藏”时要勾选具体规则，也可以选“现有规则不覆盖”并写一句原因。
- 一个独立的 **值得看 / 撤销值得看** 按钮。
- **撤销标注**。
- 一个单独的 **暂时隐藏 / 恢复** 按钮，它只改这条帖子当前显示与否，**不算标注**。

保存成功才显示“已标注”。保存失败要保留你的选择并允许重试。

### 3.3 工具条

页面上有一个可拖动的小工具条（拖动标题行，方向键微调，双击或 Home 复位；不会被拖出窗口）。默认只显示一行，点“筛选”展开筛选项：

- 显示“复核模式”，并有**暂停 / 退出**按钮。
- 显示范围：全部 / 拟隐藏 / 拟保留 / 未决 / 值得看 / 已标注，也可以按具体规则筛。
- “命中分不低于 X”滑杆：只在选了某条规则时可用，未评分和本地广告不参与。
- 计数：当前已加载 N 条，筛走 M 条，已标注 K 条。有“显示全部”入口。

动画可以关闭，并遵守系统的“减少动态效果”设置。控件不能盖住 X 原有的点赞、转发等按钮。

## 4. 范围

**首期包含**：X 主页的复核模式，规则/分数展示，标注与撤销，金色手动标记，工具条筛选与滑杆。搜索页和回复页在主页验收后再加。

**首期不包含**：模型自动推荐金色、优先阅读队列、主动通知、自动滚动、邮件/消息/列表、自动改规则、自动训练。

## 5. 数据与隐私

- 标注记录包含：帖子文本快照（含必要的引用/父帖）、规则内容与阈值的指纹、每条规则的分数或未回答原因、你的标注、时间。
- 存在浏览器本地，与现有采集样本库分开存放；有数量上限，可以整体删除或逐条撤销。
- 复核模式**本身不发任何新请求**，也不额外调用 Jev、OpenAI 或 DeepSeek。正常过滤原本会产生的请求不变。
- 原文不写入日志或遥测。

## 6. 和质量评估的关系

复核模式里的标注是你**看到模型提示后**做的，只能用来发现问题、积累候选样本。正式的准确率、误隐藏率、漏过滤率，仍然靠不显示模型结果的随机盲审来算（进展见现有的评估执行计划）。两类数据分开存、分开报告，不混算。

## 7. 验收用例

| # | 场景 | 期望 |
| --- | --- | --- |
| 1 | 复核模式默认开启，是一个全局设置 | 新装后每个 X 页面直接进入复核模式；在设置里关闭后，所有页面（含之后新开的）恢复正常隐藏，刷新不改变状态 |
| 2 | 开启复核，出现命中规则的帖子 | 帖子仍然可见，显示棕红边框和命中规则 |
| 3 | 开启复核，出现没命中的帖子 | 适用规则都已判断时显示绿色，否则显示琥珀并说明原因 |
| 4 | 帖子还在请求或请求失败 | 显示琥珀，不显示绿色 |
| 5 | 退出复核 | 所有注入的边框和控件消失，按正常设置重新隐藏 |
| 6 | 标注一条帖子 | 保存成功后显示已标注；刷新页面、帖子再次出现，仍对得上这条标注 |
| 7 | 只勾选一条规则并选“应保留” | 其他规则不会被记成“没命中” |
| 8 | 点“值得看” | 边框变金色；撤销后恢复原状态 |
| 9 | 拖动分数滑杆 | 只改变显示范围；不产生模型请求，也不改设置里的阈值 |
| 10 | 线程里一条命中、其他回复被联动 | 只有命中那条标“本帖命中”，其他标“线程联动” |
| 11 | X 页面回收并复用节点 | 标注和颜色不会串到别的帖子上 |
| 12 | 停止复核或清空数据后，迟到的模型结果返回 | 不会重新上色或覆盖新状态 |
| 13 | 用键盘操作 | 能聚焦、展开、标注、撤销 |

## 8. 待定事项

- 单条“暂时隐藏”恢复入口的具体位置与样式。
- 工具条位置是否跨页面记忆（首期只在当前页面内记忆）。
- 页面刷新后是否需要恢复复核状态（首期默认不恢复）。
- 标注库的容量与保留时长（设计文档给了默认值，可调整）。
